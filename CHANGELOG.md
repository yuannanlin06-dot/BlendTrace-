# Changelog

## 0.2.0

- Added an offline semantic cursor overlay inside Blender's 3D View.
- Cursor points to the active object's origin and displays the latest captured operation.
- Added a user toggle for the semantic cursor.
- Added explicit privacy boundaries for OS mouse input, clipboard, files, credentials and networking.
- Kept the extension dependency-free and local-only.

## 0.1.1

- Fixed undo-stack active step reading.
- Added release, privacy and security documentation.
